# Largest core-family component note

The largest frozen core-family component contains **13,623 people**, or **2.06%** of the 661,124-person master population; its modal dynasty is Tang. It is a clear size outlier even though it remains below the predeclared 5% giant-component warning threshold.

The frozen family-group split is retained unchanged. This component is assigned as one indivisible family group, so it cannot cross train, validation, and test. Phase 2 reports descriptive metrics both with and without this component as a sensitivity check. Excluding it is not used to redefine, tune, or regenerate the frozen held-out split, and its presence is not treated as a blocker.
