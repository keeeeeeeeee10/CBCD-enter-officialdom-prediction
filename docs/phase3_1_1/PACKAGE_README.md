# CBDB Phase 3.1.1 course-submission package

This archive contains author and anonymous PDFs, their LaTeX/BibTeX sources, locally generated figures, small frozen source tables, non-experimental Phase 3.1.1 scripts, tests, audits, environment files, and deterministic manifests.

Run `bash scripts/run_phase3_1_1_final_polish.sh` from a complete frozen project checkout. The archive intentionally excludes CBDB SQLite files, models, large feature matrices, model caches, and full intermediate predictions. CBDB must be obtained through its official access channel; the project MIT license does not grant data-redistribution rights.

The internal `manifest/MANIFEST.tsv` and `manifest/SHA256SUMS` cover every payload file except the two manifest files themselves. An external `.sha256` file records the archive hash.
